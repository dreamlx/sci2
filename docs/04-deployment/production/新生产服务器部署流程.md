# 新生产服务器部署流程

## 概述

本文档说明从旧服务器 (192.168.9.209) 迁移到新生产服务器 (100.98.75.43) 的完整流程。

## 服务器信息

| 服务器 | 地址 | 用户 | 数据库 | 说明 |
|--------|------|------|--------|------|
| 旧服务器 | 192.168.9.209 | test | SQLite | 当前生产环境 |
| 新服务器 | 100.98.75.43 | test | PostgreSQL | 新生产环境 |
| 本地开发 | localhost | - | PostgreSQL (Docker) | 开发测试环境 |

## 部署流程

### 1. 从旧服务器下载 SQLite 数据库

```bash
# 运行迁移脚本
./scripts/deploy/migrate_sqlite_to_postgres.sh
```

此脚本会：
- 从旧服务器下载 SQLite 数据库
- 将 SQLite 数据导出为 CSV
- 导入到本地 PostgreSQL
- 运行数据库迁移
- 验证数据完整性

### 2. 本地测试验证

```bash
# 运行验证脚本
./scripts/deploy/verify_local.sh
```

此脚本会：
- 检查数据库连接
- 验证数据完整性
- 检查数据一致性
- 启动 Rails 服务器
- 测试 ActiveAdmin 界面
- 生成测试报告

### 3. 部署到新生产服务器

```bash
# 运行部署脚本
./scripts/deploy/deploy_to_new_production.sh
```

此脚本会：
- 检查依赖和环境
- 测试 SSH 连接
- 执行 Capistrano 部署
- 上传配置文件
- 重启服务
- 验证部署结果

## 详细步骤

### 步骤 1: 准备工作

#### 1.1 检查本地环境

```bash
# 检查 Ruby 版本
ruby -v  # 应该是 3.4.2

# 检查 Docker 容器
docker compose ps

# 启动 PostgreSQL 容器（如果未运行）
docker compose up -d
```

#### 1.2 配置 SSH 密钥

```bash
# 生成 SSH 密钥（如果没有）
ssh-keygen -t rsa -b 4096 -C "deploy@sci2"

# 复制公钥到服务器
ssh-copy-id test@192.168.9.209
ssh-copy-id test@100.98.75.43

# 测试连接
ssh test@192.168.9.209
ssh test@100.98.75.43
```

### 步骤 2: 数据迁移

#### 2.1 从旧服务器下载 SQLite 数据库

```bash
# 运行迁移脚本
./scripts/deploy/migrate_sqlite_to_postgres.sh
```

脚本执行流程：
1. 检查依赖（ssh, sqlite3）
2. 测试 SSH 连接到旧服务器
3. 下载 SQLite 数据库文件
4. 显示数据库信息
5. 备份本地 PostgreSQL 数据库
6. 重建本地数据库
7. 运行数据库迁移
8. 导出 SQLite 数据到 CSV
9. 导入 CSV 数据到 PostgreSQL
10. 验证数据完整性

#### 2.2 验证数据迁移

```bash
# 检查数据库统计
docker compose exec postgres_test psql -U sci2_test sci2_development << EOF
  SELECT 'Reimbursements' as table_name, COUNT(*) as count FROM reimbursements
  UNION ALL
  SELECT 'Work Orders', COUNT(*) FROM work_orders
  UNION ALL
  SELECT 'Admin Users', COUNT(*) FROM admin_users;
EOF
```

### 步骤 3: 本地测试

## 回滚操作

如果部署出现问题，可以执行回滚：

```bash
# 回滚到上一个版本
RBENV_VERSION=3.4.2 bundle exec cap new_production deploy:rollback

# 查看部署历史
RBENV_VERSION=3.4.2 bundle exec cap new_production deploy:status
```

## 故障排除

### 问题 1: SSH 连接失败

**解决方案**：
```bash
# 检查 SSH 密钥
ls -la ~/.ssh/

# 测试连接
ssh -v test@192.168.9.209
ssh -v test@100.98.75.43

# 重新复制密钥
ssh-copy-id test@192.168.9.209
ssh-copy-id test@100.98.75.43
```

### 问题 2: Docker 容器未运行

**解决方案**：
```bash
# 启动容器
docker compose up -d

# 查看容器状态
docker compose ps

# 查看容器日志
docker compose logs -f postgres_test
```

### 问题 3: 数据库迁移失败

**解决方案**：
```bash
# 检查数据库连接
docker compose exec postgres_test pg_isready -U sci2_test

# 重建数据库
docker compose exec postgres_test psql -U sci2_test postgres << EOF
  DROP DATABASE IF EXISTS sci2_development;
  CREATE DATABASE sci2_development OWNER sci2_test;
EOF

# 重新运行迁移
RBENV_VERSION=3.4.2 DATABASE_PORT=55000 DATABASE_USERNAME=sci2_test DATABASE_PASSWORD=test_password_123 bundle exec rails db:migrate
```

### 问题 4: Capistrano 部署失败

**解决方案**：
```bash
# 检查 Capistrano 配置
RBENV_VERSION=3.4.2 bundle exec cap new_production deploy:check

# 查看详细日志
RBENV_VERSION=3.4.2 bundle exec cap new_production deploy --trace

# 手动执行部署任务
RBENV_VERSION=3.4.2 bundle exec cap new_production deploy:setup_server
```
