## 开发环境

### 系统要求

- **操作系统**: macOS (推荐) 或 Linux
- **Ruby 版本**: 3.4.2 (使用 rbenv 管理)
- **Rails 版本**: 7.1.3
- **Node.js**: 用于前端资源编译
- **PostgreSQL**: 15+ (通过 Docker Compose)

### 安装步骤

#### 1. 安装 rbenv

```bash
# macOS
brew install rbenv ruby-build

# 添加到 shell 配置
echo 'export PATH="$HOME/.rbenv/bin:$PATH"' >> ~/.zshrc
echo 'eval "$(rbenv init -)"' >> ~/.zshrc
source ~/.zshrc
```

#### 2. 安装 Ruby 3.4.2

```bash
rbenv install 3.4.2
rbenv local 3.4.2
```

#### 3. 安装 Bundler

```bash
gem install bundler -v 2.5.23
```

#### 4. 安装项目依赖

```bash
# 安装 Ruby 依赖
RBENV_VERSION=3.4.2 bundle install

# 安装 Node.js 依赖
npm install
```

#### 5. 启动 PostgreSQL 容器

```bash
docker compose up -d
```

## 生产环境

### 系统要求

- **操作系统**: Ubuntu 22.04 LTS (推荐)
- **CPU**: 2vCPU
- **内存**: 4GB RAM
- **存储**: 40GB SSD
- **网络**: 可访问 Git 仓库

### 软件依赖

```bash
# 必需软件
- Ruby 3.4.2 (通过系统 RVM 管理)
- Bundler 2.5.23
- Git
- PostgreSQL 15+
- Nginx
- Node.js (用于资产预编译)
```

### 服务器初始化脚本

```bash
#!/bin/bash
# scripts/deploy/server_setup.sh

set -e

echo "=== 更新系统 ==="
sudo apt-get update && sudo apt-get upgrade -y

echo "=== 安装基础软件 ==="
sudo apt-get install -y curl git build-essential libssl-dev libreadline-dev \
  zlib1g-dev libpq-dev postgresql postgresql-contrib nginx nodejs npm

echo "=== 安装 RVM ==="
gpg --keyserver hkp://keyserver.ubuntu.com --recv-keys \
  409B6B1796C275462A1703113804BB82D39DC0E3 \
  7D2BAF1CF37B13E2069D6956105BD0E739499BDB

curl -sSL https://get.rvm.io | bash -s stable
source /etc/profile.d/rvm.sh

echo "=== 安装 Ruby 3.4.2 ==="
rvm install 3.4.2
rvm use 3.4.2 --default

echo "=== 安装 Bundler ==="
gem install bundler -v 2.5.23

echo "=== 创建部署用户 ==="
sudo useradd -m -s /bin/bash deploy
sudo mkdir -p /home/deploy/.ssh
sudo chown -R deploy:deploy /home/deploy/.ssh
sudo chmod 700 /home/deploy/.ssh

echo "=== 创建部署目录 ==="
sudo mkdir -p /opt/sci2
sudo chown -R deploy:deploy /opt/sci2

echo "=== 服务器初始化完成 ==="
```

## 环境变量配置

### 开发环境

```bash
# .env.development
DATABASE_HOST=localhost
DATABASE_PORT=55000
DATABASE_USERNAME=sci2_test
DATABASE_PASSWORD=test_password_123
DATABASE_NAME=sci2_development
DATABASE_NAME_TEST=sci2_test
RAILS_ENV=development
```

```bash
# .env.test
DATABASE_HOST=localhost
DATABASE_PORT=55000
DATABASE_USERNAME=sci2_test
DATABASE_PASSWORD=test_password_123
DATABASE_NAME_TEST=sci2_test
```

```ruby

set :env_variables, {

  'DATABASE_USERNAME' => 'sci2',

  'DATABASE_HOST' => '127.0.0.1',
  'DATABASE_PORT' => '5432',
  'DATABASE_NAME_PROD' => 'sci2_production'

```

## 数据库配置

### PostgreSQL 安装

#### 开发环境 (Docker Compose)

```yaml
# docker-compose.yml
services:
  postgres_test:
    image: postgres:15-alpine
    container_name: sci2_test_db
    environment:
      POSTGRES_USER: sci2_test
      POSTGRES_PASSWORD: test_password_123
      POSTGRES_DB: sci2_test
    ports:
      - "55000:5432"
    volumes:
      - postgres_test_data:/var/lib/postgresql/data
```

#### 生产环境 (直接安装)

```bash
# 安装 PostgreSQL
sudo apt-get install postgresql postgresql-contrib

# 创建数据库和用户
sudo -u postgres psql
CREATE USER sci2 WITH PASSWORD 'password_123';
CREATE DATABASE sci2_production OWNER sci2;
GRANT ALL PRIVILEGES ON DATABASE sci2_production TO sci2;
\q
```

### 数据库配置文件

```yaml
# config/database.yml
default: &default
  adapter: postgresql
  encoding: unicode
  pool: <%= ENV.fetch("RAILS_MAX_THREADS") { 10 } %>
  username: <%= ENV.fetch("DATABASE_USERNAME") { "sci2" } %>
  password: <%= ENV.fetch("DATABASE_PASSWORD") { "password_123" } %>
  host: <%= ENV.fetch("DATABASE_HOST") { "127.0.0.1" } %>
  port: <%= ENV.fetch("DATABASE_PORT") { 5432 } %>

development:
  <<: *default
  database: <%= ENV.fetch("DATABASE_NAME") { "sci2_development" } %>

test:
  <<: *default
  database: <%= ENV.fetch("DATABASE_NAME_TEST") { "sci2_test" } %>

production:
  <<: *default
  pool: <%= ENV.fetch("RAILS_MAX_THREADS") { 20 } %>
  database: <%= ENV.fetch("DATABASE_NAME_PROD") { "sci2_production" } %>
```

## 验证环境

### 开发环境验证

```bash
# 检查 Ruby 版本
ruby -v  # 应该显示 ruby 3.4.2

# 检查 Rails 版本
rails -v  # 应该显示 Rails 7.1.3

# 检查 PostgreSQL 连接
docker compose exec postgres_test psql -U sci2_test -d sci2_test -c "SELECT version();"

# 运行测试
DATABASE_PORT=55000 RAILS_ENV=test bundle exec rspec
```

### 生产环境验证

```bash
# 检查 Ruby 版本
ruby -v  # 应该显示 ruby 3.4.2

# 检查 PostgreSQL 连接
psql -h 127.0.0.1 -U sci2 -d sci2_production -c "SELECT version();"

# 检查 Capistrano 配置
bundle exec cap production deploy:check
```
