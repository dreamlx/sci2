## 快速开始

### 1. 克隆项目

```bash
git clone git@gitee.com:dreamlx/sci2.git
cd sci2
```

### 2. 设置 Ruby 版本

```bash
rbenv local 3.4.2
```

### 3. 安装依赖

```bash
# 安装 Ruby 依赖
RBENV_VERSION=3.4.2 bundle install

# 安装 Node.js 依赖
npm install
```

### 4. 启动 PostgreSQL

```bash
docker compose up -d
```

### 5. 初始化数据库

```bash
# 创建数据库
RAILS_ENV=test bundle exec rails db:create

# 运行迁移
RAILS_ENV=test bundle exec rails db:migrate

# 加载种子数据
RAILS_ENV=test bundle exec rails db:seed
```

### 6. 启动开发服务器

```bash
# 开发环境
rails server

# 或使用 rbenv 指定版本
RBENV_VERSION=3.4.2 rails server
```

访问 `http://localhost:3000/admin/login` 进入管理界面。

## 数据库设置

### Docker Compose PostgreSQL

项目使用 Docker Compose 运行 PostgreSQL 测试数据库：

```yaml
# docker-compose.yml
version: '3.8'
services:
  postgres_test:
    image: postgres:15-alpine
    container_name: sci2_test_db
    restart: always
    environment:
      POSTGRES_USER: sci2_test
      POSTGRES_PASSWORD: test_password_123
      POSTGRES_DB: sci2_test
    ports:
      - "55000:5432"
    volumes:
      - postgres_test_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U sci2_test -d sci2_test"]
      interval: 5s
      timeout: 5s
      retries: 5

volumes:
  postgres_test_data:
    driver: local
```

### 容器管理命令

```bash
# 启动容器
docker compose up -d

# 查看容器状态
docker ps | grep sci2_test_db

# 查看容器日志
docker compose logs -f postgres_test

# 进入容器
docker compose exec postgres_test psql -U sci2_test -d sci2_test

# 停止容器
docker compose down

# 重启容器
docker compose down && docker compose up -d
```

### 本地 PostgreSQL（备选）

如果不想使用 Docker Compose，可以安装本地 PostgreSQL：

```bash
# macOS
brew install postgresql@15
brew services start postgresql@15

# Ubuntu
sudo apt-get install postgresql postgresql-contrib

# 创建数据库
createdb sci2_development
createdb sci2_test

# 配置环境变量
export DATABASE_HOST=localhost
export DATABASE_PORT=5432
export DATABASE_USERNAME=your_username
export DATABASE_PASSWORD=your_password
```

## 启动服务

### 开发服务器

```bash
# 启动 Rails 服务器
rails server

# 指定端口
rails server -p 3001

# 指定环境
RAILS_ENV=development rails server
```

### 后台运行

```bash
# 使用 nohup 后台运行
nohup rails server > log/development.log 2>&1 &

# 使用 Foreman（需要安装 foreman gem）
gem install foreman
foreman start
```

## 运行测试

### 运行所有测试

```bash
DATABASE_PORT=55000 RAILS_ENV=test bundle exec rspec
```

### 运行特定测试文件

```bash
DATABASE_PORT=55000 RAILS_ENV=test bundle exec rspec spec/models/reimbursement_spec.rb
```

### 运行特定测试

```bash
DATABASE_PORT=55000 RAILS_ENV=test bundle exec rspec spec/models/reimbursement_spec.rb:42
```

### 运行特定目录的测试

```bash
# 模型测试
DATABASE_PORT=55000 RAILS_ENV=test bundle exec rspec spec/models/

# 服务测试
DATABASE_PORT=55000 RAILS_ENV=test bundle exec rspec spec/services/

# 功能测试
DATABASE_PORT=55000 RAILS_ENV=test bundle exec rspec spec/features/
```

```bash

COVERAGE=true DATABASE_PORT=55000 RAILS_ENV=test bundle exec rspec

open coverage/index.html
```

## 常见问题

### 问题 1: 数据库连接失败

**症状**: `could not connect to server: Connection refused`

**解决方案**:

```bash
# 检查 PostgreSQL 容器是否运行
docker ps | grep sci2_test_db

# 如果没有运行，启动容器
docker compose up -d

# 检查端口是否被占用
lsof -i :55000

# 查看容器日志
docker compose logs postgres_test
```

### 问题 2: Ruby 版本不匹配

**症状**: `Your Ruby version is 3.3.0, but your Gemfile specified 3.4.2`

**解决方案**:

```bash
# 检查已安装的 Ruby 版本
rbenv versions

# 安装 Ruby 3.4.2
rbenv install 3.4.2

# 设置本地 Ruby 版本
rbenv local 3.4.2

# 验证版本
ruby -v
```

### 问题 3: Bundle 安装失败

**症状**: `An error occurred while installing pg`

**解决方案**:

```bash
# 安装 PostgreSQL 开发库
# macOS
brew install postgresql

# Ubuntu
sudo apt-get install libpq-dev

# 重新安装依赖
RBENV_VERSION=3.4.2 bundle install
```

### 问题 4: Docker 容器端口冲突

**症状**: `Bind for 0.0.0.0:55000 failed: port is already allocated`

**解决方案**:

```bash
# 检查端口占用
lsof -i :55000

# 停止占用端口的进程
kill -9 <PID>

# 或修改 docker-compose.yml 中的端口映射
ports:
  - "55001:5432"  # 使用不同的端口
```

### 问题 5: 测试数据库迁移失败

**解决方案**:

```bash
# 重置测试数据库
RAILS_ENV=test bundle exec rails db:reset

# 检查迁移状态
RAILS_ENV=test bundle exec rails db:migrate:status

# 运行特定迁移
RAILS_ENV=test bundle exec rails db:migrate:up VERSION=20250101000000
```

## 开发工具

### Rubocop 代码检查

```bash
# 运行代码检查
bundle exec rubocop

# 自动修复
bundle exec rubocop -a

# 检查特定文件
bundle exec rubocop app/models/reimbursement.rb
```

### Rails 控制台

```bash
# 开发环境
rails console

# 测试环境
RAILS_ENV=test rails console

# 生产环境
RAILS_ENV=production rails console
```

### 数据库控制台

```bash
# 使用 Rails dbconsole
rails dbconsole

# 直接使用 psql
psql -h localhost -p 55000 -U sci2_test -d sci2_test
```
