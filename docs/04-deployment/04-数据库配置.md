## 数据库架构

### 数据库选择

SCI2 项目使用 PostgreSQL 作为所有环境的数据库：

| 环境 | 数据库 | 部署方式 |
|------|--------|----------|
| 开发 | PostgreSQL 15 | Docker Compose |
| 测试 | PostgreSQL 15 | Docker Compose |
| 生产 | PostgreSQL 15 | 直接安装 |

### 数据库配置文件

```yaml
# config/database.yml
default: &default
  adapter: postgresql
  encoding: unicode
  pool: <%= ENV.fetch("RAILS_MAX_THREADS") { 10 } %>
  username: <%= ENV.fetch("DATABASE_USERNAME") { "sci2" } %>
  password: <%= ENV.fetch("DATABASE_PASSWORD") { "password_123" } %>
  host: <%= ENV.fetch("DATABASE_HOST") { "127.0.0.1" } %>
  port: <%= ENV.fetch("DATABASE_PORT") { 5432 } %>

development:
  <<: *default
  database: <%= ENV.fetch("DATABASE_NAME") { "sci2_development" } %>

test:
  <<: *default
  database: <%= ENV.fetch("DATABASE_NAME_TEST") { "sci2_test" } %>

production:
  <<: *default
  pool: <%= ENV.fetch("RAILS_MAX_THREADS") { 20 } %>
  database: <%= ENV.fetch("DATABASE_NAME_PROD") { "sci2_production" } %>
```

## 开发环境配置

### Docker Compose PostgreSQL

```yaml
# docker-compose.yml
version: '3.8'
services:
  postgres_test:
    image: postgres:15-alpine
    container_name: sci2_test_db
    restart: always
    environment:
      POSTGRES_USER: sci2_test
      POSTGRES_PASSWORD: test_password_123
      POSTGRES_DB: sci2_test
    ports:
      - "55000:5432"
    volumes:
      - postgres_test_data:/var/lib/postgresql/data
      - ./docker/postgres/init:/docker-entrypoint-initdb.d
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U sci2_test -d sci2_test"]
      interval: 5s
      timeout: 5s
      retries: 5
      start_period: 10s

volumes:
  postgres_test_data:
    driver: local
```

### 容器管理

```bash
# 启动容器
docker compose up -d

# 查看容器状态
docker ps | grep sci2_test_db

# 查看容器日志
docker compose logs -f postgres_test

# 进入容器
docker compose exec postgres_test psql -U sci2_test -d sci2_test

# 停止容器
docker compose down

# 重启容器
docker compose down && docker compose up -d
```

### 本地 PostgreSQL（备选）

如果不想使用 Docker Compose，可以安装本地 PostgreSQL：

```bash
# macOS
brew install postgresql@15
brew services start postgresql@15

# Ubuntu
sudo apt-get install postgresql postgresql-contrib

# 创建数据库和用户
sudo -u postgres psql
CREATE USER sci2 WITH PASSWORD 'password_123';
CREATE DATABASE sci2_development OWNER sci2;
CREATE DATABASE sci2_test OWNER sci2;
GRANT ALL PRIVILEGES ON DATABASE sci2_development TO sci2;
GRANT ALL PRIVILEGES ON DATABASE sci2_test TO sci2;
\q
```

## 生产环境配置

### 安装 PostgreSQL

```bash
# 安装 PostgreSQL
sudo apt-get update
sudo apt-get install postgresql postgresql-contrib

# 启动 PostgreSQL
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

### 配置 PostgreSQL

```bash
# 编辑 PostgreSQL 配置
sudo nano /etc/postgresql/15/main/postgresql.conf

# 修改以下配置
listen_addresses = '127.0.0.1'
max_connections = 100
shared_buffers = 256MB
effective_cache_size = 1GB
maintenance_work_mem = 64MB
checkpoint_completion_target = 0.9
wal_buffers = 16MB
default_statistics_target = 100
random_page_cost = 1.1
effective_io_concurrency = 200
work_mem = 2621kB
min_wal_size = 1GB
max_wal_size = 4GB

# 重启 PostgreSQL
sudo systemctl restart postgresql
```

### 创建数据库和用户

```bash
# 切换到 postgres 用户
sudo -u postgres psql

# 创建用户
CREATE USER sci2 WITH PASSWORD 'password_123';

# 创建数据库
CREATE DATABASE sci2_production OWNER sci2;

# 授权
GRANT ALL PRIVILEGES ON DATABASE sci2_production TO sci2;
ALTER DATABASE sci2_production OWNER TO sci2;

# 退出
\q
```

### 配置 pg_hba.conf

```bash
# 编辑 pg_hba.conf
sudo nano /etc/postgresql/15/main/pg_hba.conf

# 添加以下行（在文件末尾）
local   sci2_production   sci2   md5
host    sci2_production   sci2   127.0.0.1/32   md5

# 重启 PostgreSQL
sudo systemctl restart postgresql
```

## 数据库迁移

### 创建数据库

```bash
# 开发环境
RAILS_ENV=development bundle exec rails db:create

# 测试环境
RAILS_ENV=test bundle exec rails db:create

# 生产环境
RAILS_ENV=production bundle exec rails db:create
```

### 运行迁移

```bash
# 运行所有待执行的迁移
RAILS_ENV=production bundle exec rails db:migrate

# 运行特定迁移
RAILS_ENV=production bundle exec rails db:migrate:up VERSION=20250101000000

# 回滚最后一个迁移
RAILS_ENV=production bundle exec rails db:rollback

# 回滚多个迁移
RAILS_ENV=production bundle exec rails db:rollback STEP=3
```

### 查看迁移状态

```bash
# 查看迁移状态
RAILS_ENV=production bundle exec rails db:migrate:status

# 查看当前数据库版本
RAILS_ENV=production bundle exec rails db:version
```

### 加载种子数据

```bash
# 加载种子数据
RAILS_ENV=production bundle exec rails db:seed

# 重置数据库（删除所有数据并重新创建）
RAILS_ENV=production bundle exec rails db:reset
```

## 备份和恢复

### 备份数据库

```bash
# 备份生产数据库
pg_dump -h 127.0.0.1 -U sci2 -d sci2_production > backup_$(date +%Y%m%d_%H%M%S).sql

# 备份并压缩
pg_dump -h 127.0.0.1 -U sci2 -d sci2_production | gzip > backup_$(date +%Y%m%d_%H%M%S).sql.gz

# 备份到 S3（需要安装 awscli）
pg_dump -h 127.0.0.1 -U sci2 -d sci2_production | gzip | aws s3 cp - s3://sci2-backups/backup_$(date +%Y%m%d_%H%M%S).sql.gz
```

### 恢复数据库

```bash
# 恢复数据库
psql -h 127.0.0.1 -U sci2 -d sci2_production < backup_file.sql

# 恢复压缩的备份
gunzip -c backup_file.sql.gz | psql -h 127.0.0.1 -U sci2 -d sci2_production

# 从 S3 恢复
aws s3 cp s3://sci2-backups/backup_file.sql.gz - | gunzip | psql -h 127.0.0.1 -U sci2 -d sci2_production
```

### 自动备份脚本

```bash
#!/bin/bash
# scripts/backup_database.sh

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/var/backups/sci2"
DB_NAME="sci2_production"
DB_USER="sci2"
DB_HOST="127.0.0.1"

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份数据库
pg_dump -h $DB_HOST -U $DB_USER -d $DB_NAME | gzip > $BACKUP_DIR/backup_$DATE.sql.gz

# 删除 7 天前的备份
find $BACKUP_DIR -name "backup_*.sql.gz" -mtime +7 -delete

# 上传到 S3（可选）
# aws s3 cp $BACKUP_DIR/backup_$DATE.sql.gz s3://sci2-backups/

echo "Backup completed: backup_$DATE.sql.gz"
```

### 设置定时备份

```bash
# 编辑 crontab
crontab -e

# 添加每天凌晨 2 点备份
0 2 * * * /path/to/scripts/backup_database.sh >> /var/log/sci2_backup.log 2>&1
```

## 性能优化

### 索引优化

```ruby
# 添加索引
add_index :reimbursements, :invoice_number
add_index :reimbursements, :status
add_index :reimbursements, :assignee_id
add_index :reimbursements, [:status, :last_update_at]

# 复合索引
add_index :work_orders, [:reimbursement_id, :type]
add_index :work_orders, [:status, :created_at]
```

### 查询优化

```ruby
# 使用 includes 预加载关联，避免 N+1 查询
Reimbursement.includes(:fee_details, :work_orders).all

# 使用 select 只查询需要的字段
Reimbursement.select(:id, :invoice_number, :status)

# 使用 where 条件过滤
Reimbursement.where(status: 'pending').where('created_at > ?', 1.month.ago)
```

### PostgreSQL 配置优化

```bash
# /etc/postgresql/15/main/postgresql.conf

# 内存配置
shared_buffers = 256MB          # 25% of RAM
effective_cache_size = 1GB       # 50-75% of RAM
maintenance_work_mem = 64MB      # 5-10% of RAM
work_mem = 2621kB                # (RAM - shared_buffers) / max_connections

# 连接配置
max_connections = 100

# WAL 配置
wal_buffers = 16MB
min_wal_size = 1GB
max_wal_size = 4GB

# 查询优化
random_page_cost = 1.1           # SSD
effective_io_concurrency = 200   # SSD
default_statistics_target = 100
```

## 监控和维护

### 查看数据库大小

```sql
-- 查看所有数据库大小
SELECT 
    pg_database.datname,
    pg_size_pretty(pg_database_size(pg_database.datname)) AS size
FROM pg_database;

-- 查看表大小
SELECT 
    schemaname,
    tablename,
    pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) AS size
FROM pg_tables
WHERE schemaname = 'public'
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC;
```

### 查看连接数

```sql
-- 查看当前连接数
SELECT count(*) FROM pg_stat_activity;

-- 查看每个数据库的连接数
SELECT 
    datname,
    count(*) 
FROM pg_stat_activity 
GROUP BY datname;
```
